# Schriftprobe — Lesbarkeit verbessern

Ziel: dieselbe Pfarrer-/Schreiberhand gezielt lernen, bevor wir
schwierige Namenszeilen entscheiden.

Methode gehört zu [`SUCHMODELL.md`](SUCHMODELL.md).

## Warum das hilft

In einem Band wechseln oft **mehrere Hände**. Wer die Hand kennt:

- verwechselt `Joaquim` nicht mit `João` / `Francisco`
- erkennt `Florencia` / `Florência` an typischen Schleifen
- liest `Fre…` vs. `Duarte` am Wortanfang sicherer
- weiß, welche Seiten **derselbe** Vigário geschrieben hat

Anti-Muster: OCR über den ganzen Band laufen lassen und dem Text trauen.

## Ablauf (pro Band / Schreiber)

1. **Signatur finden** — am Eintragsende meist `Vigario …` / `Parocho …`.
2. **Ankerseiten wählen** — 3–5 Einträge mit klaren Standardwörtern
   (Datum, `filho`, `filha`, `natural`, Ortsnamen am Rand).
3. **Buchstabenkarte füllen** — unten; nur Formen aus **dieser** Hand.
4. **Zielzeile dagegenhalten** — Elternzeile erst danach festlesen.
5. **Handwechsel notieren** — neue Signatur = neue Karte.

## Buchstabenkarte (Vorlage)

Für **eine** Hand ausfüllen (Beispiel: Vigario Barata, Alvorge ~1828):

| Zeichen / Wort | typische Form (Notiz) | Beleg-Bild |
| --- | --- | --- |
| `F` / `Fevereiro` | | m0050 |
| `J` / `Joaquim` / `João` / `Jozé` | | |
| `M` / `Maria` / `Manoel` | | |
| `Fl` / `Florencia` | | sobald Anker gefunden |
| `Fr` / `Francisco` / `Freire` / `Fre…` | Wortanfang kritisch | |
| `D` / `Duarte` / `dos` | | |
| `R` / `Roza` / `Rodrigues` | | |
| `x` (zwischen Eheleuten) | | |
| Rand-Lugar (`Vale Paio`, `Ateanha`, …) | oft andere Feder/Kürze | |

Unsichere Lesung: in `[]` lassen und Crop nach `evidenz/scans/` legen.

## Nächster praktischer Schritt

1. Alvorge `m0040–m0120` (~1826–1834): nur Einträge von **Barata** (oder Nachfolger) markieren.
2. Drei klare `Joaquim`-/`Maria`-Zeilen als Anker in die Buchstabenkarte.
3. Dann gezielt nach **Joaquim × Florencia** + Kind **Roza** suchen.
