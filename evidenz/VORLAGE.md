# Vorlage — Evidenzblatt

Kopie nach `evidenz/linie-…/….md`. Dateinamen klein, bindestriche.
Leere Felder als `offen` stehen lassen, nicht raten.

Beispiel: [linie-duarte/G2-heirat-1907.md](linie-duarte/G2-heirat-1907.md).

```md
# Linie — Kurzname

| Person |  |  |  |
| Eltern / Partner |  |  |  |
| Herkunft | Originalakt / Familienunterlage / mündliche Angabe / Schlussfolgerung |  |  |

## Quellen

- Portal:

## Anschluss

## Offene Lesungen

Was in `[]` bleibt. Frühere andere Lesung nicht streichen.
```
