# Name → Ordner → Scan

Zum **Durchforsten**. Jeder Name hat einen Ordner. Dieselben Pixel
liegen zweimal: hier unter sprechendem Dateinamen, in `*-records/`
unter der Archivsignatur. Zuerst **`archiv/`** öffnen.

Linien nicht mischen. Duarte bleibt Duarte. Torre/Reis bleibt Torre.

Blatt mit Transkript: [`evidenz/quellenregister.md`](../evidenz/quellenregister.md).
